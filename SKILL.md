# MDM Nomenclature Search Skill

## Описание
Поиск по справочнику МДМ номенклатуры строительных материалов. База содержит 89 312 позиций с кодами, классами и статусами.

## Когда использовать
- Пользователь спрашивает код номенклатуры по названию
- Поиск позиции по коду МДМ
- Подбор номенклатуры для спецификации
- Проверка статуса позиции (Эталон/Стандарт/Архив)

## Данные
- **Файл:** `data/mdm_nomenclature.jsonl` (28 МБ, 89 312 записей)
- **Формат записи:** `{"name", "code", "class", "class_code", "status", "unit", "article", "gt"}`

## Статусы (приоритет поиска)
1. **Эталон** (75 218 позиций) — высший приоритет
2. **Стандарт** (11 099 позиций) — средний
3. **Архив** (2 995 позиций) — низший

## Поиск

### По названию (нечёткий)
```bash
python3 scripts/search.py --name "арматура A500C" --limit 10
python3 scripts/search.py --name "кабель" --status Эталон --limit 5
```

### По коду (точный)
```bash
python3 scripts/search.py --code "00000000003"
```

### По коду (префикс)
```bash
python3 scripts/search.py --code "0000000" --prefix --limit 20
```

### Фильтры
- `--status` — Эталон | Стандарт | Архив
- `--class` — фильтр по классу (например, "Арматура")
- `--limit N` — количество результатов (по умолчанию 10)

## Обновление базы
Когда Алексей присылает новый XLSX файл:
1. Прочитать новый файл через openpyxl
2. Загрузить существующие коды из JSONL в set
3. Добавить только новые записи (которых нет по коду)
4. Сохранить обновлённый JSONL
5. НЕ пересоздавать базу полностью

## Инструкции для агента
- При поиске по названию всегда показывай топ-5 результатов с указанием: название, код, статус, единица
- Если точного совпадения нет — предлагай ближайшие с пояснением "Похожие позиции:"
- Приоритет Эталон > Стандарт > Архив — всегда учитывай при ранжировании
- Если пользователь спрашивает про класс — перечисли доступные классы
